## [1.0.0] - 2026-10-24

### Added

- **`start-from-here` Agent Skill** (`skills/start-from-here/`), following the Agent Skills open standard:
  - `SKILL.md` orchestrator (< 500 lines, self-sufficient) with hard rules, quick commands, output modes (filesystem / chat-only), and an 8-phase workflow with explicit gates: Orient → Calibrate → Discover → Recommend → Confirm brief → Generate → Audit → Handoff.
  - Three tiers (Lite / Standard / Enterprise) with a per-doc applicability matrix, plus beginner, intermediate, and expert experience modes.
  - Resumable progress via `docs/.start-from-here/STATE.md`. Brownfield mode inspects existing repos and merges without overwriting.
  - References: workflow, discovery question bank, stack recommendation, tiering matrix, document catalog, consistency audit, writing conventions, legal and compliance primer, experience modes, existing-project mode.
  - Tech-agnostic templates for product (PRD, APP_FLOW, DESIGN_SYSTEM), technical (TRD, ARCHITECTURE, DATABASE, API, SECURITY_ARCHITECTURE, TESTING, OPERATIONS, IMPLEMENTATION_PLAN), engineering and AI governance (CODE_STYLE, AI_GUIDELINES, GIT_WORKFLOW, AGENTS.md, CLAUDE.md, GEMINI.md), decisions (MADR ADRs), legal (Terms, Privacy, Cookie, Compliance), and open-source/GitHub files (README, CHANGELOG, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, SUPPORT, ACCESSIBILITY). License guidance bundles the MIT and proprietary texts.
  - Optional zero-dependency `scripts/check-docs.mjs` that reports missing docs, leftover markers, and broken relative links.
- **Zero-dependency installer CLI** (`npx start-from-here`, Node ≥ 18): `install`, `uninstall`, `list-agents`, `doctor`, `bundle`, `check`. It supports 25+ agents with research-backed paths (unverified ones are flagged), shares one copy across agents through `.agents/skills/`, copies by default with an optional `--symlink`, never overwrites without `--force`, supports `--dry-run`, and prints pointer instructions for rules-only agents (Aider, Amazon Q, JetBrains AI Assistant).
- **Distribution artifacts** in `dist/`: an upload-ready `start-from-here.zip`, a single-file `start-from-here.prompt.md`, `knowledge/` files (≤ 10) for Custom GPTs and Gems, `gpt-instructions.md` / `gem-instructions.md` bootloaders, and `SHA256SUMS`.
- **Plugin and extension manifests**: Claude Code plugin and marketplace (`.claude-plugin/`), Codex plugin (`.codex-plugin/`), and Gemini CLI extension (`gemini-extension.json`, `GEMINI-EXTENSION.md`, `commands/start-from-here.toml`).
- **Documentation**: user manual (`docs/USAGE.md`) and per-platform guides with a compatibility matrix and an install decision tree (`docs/guides/`).
- **Repository governance**: README, MIT LICENSE, CONTRIBUTING, CODE_OF_CONDUCT (Contributor Covenant 2.1), SECURITY policy, AGENTS.md, issue forms, PR template, CODEOWNERS, and maintenance scripts (`validate`, `build`, `test`).
