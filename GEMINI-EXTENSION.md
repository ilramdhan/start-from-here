# start-from-here (Gemini CLI extension context)

This extension provides the `start-from-here` Agent Skill (in `skills/start-from-here/`) and the `/start-from-here` command.

- Use the skill when the user wants to start a new project, plan an idea, kick off or document a repository before coding, or asks for a PRD, TRD, architecture, or AGENTS.md.
- To start, activate the `start-from-here` skill and follow its SKILL.md exactly, phase by phase. Respect every gate: ask, then STOP and wait for the user.
- Never write application code while following the procedure. The output is documentation only.
- Shortcut: `/start-from-here [what you want to build]`.
