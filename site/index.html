Why plan before you prompt?

“Vibe coding” — asking an AI to build an app straight from a one-line idea — feels fast. But the agent has to guess.

The problem

  • Silent guessesScope, users, data model, permissions, security rules and conventions are all invented on the fly. Every guess becomes code.
  • Expensive reworkWrong guesses surface late — after the schema, the auth flow and the UI are built on top of them.
  • No shared memoryA new session, a new model or a new teammate starts from zero, because nothing was written down.

The solution

  • It interviews youShort rounds of numbered questions, each with a labeled recommended default.
  • It recommends, you decideNo stack yet? You get 2–3 options with trade-offs and one marked Recommended.
  • It writes consistent docsShared IDs link every document, and a final audit cross-checks them.
  • It never makes things upUnknowns become [TBD], ideas become PROPOSAL, guesses become ASSUMPTION.
  • It never writes app codeIts job ends with approved documents, a readiness checklist and a first implementation prompt.

How it works

Eight phases with explicit gates. The skill stops at every gate and waits for your answer.

  1. 0
    Orient

    New project, existing repo, resume or doc update? Can it write files here?

  2. 1
    Calibrate STOP · you approve

    Language, experience, idea and size. Proposes a tier and the doc list.

  3. 2
    Discover

    Rounds of up to 7 questions, each with a recommended default.

  4. 3
    Recommend STOP · you approve

    2–3 stack, hosting or license options with trade-offs.

  5. 4
    Confirm brief STOP · you approve

    Writes docs/DISCOVERY.md and shows a short summary.

  6. 5
    Generate STOP · you approve

    Writes docs in dependency order, in review batches.

  7. 6
    Audit

    Cross-checks scope, names, stack, roles, NFRs, legal and links.

  8. 7
    Handoff

    Readiness checklist, open questions and a first implementation prompt.

  9. →
    You build with any agent

Experience modes

Chosen in the first round, or inferred from how you write.

Beginner

Explains every technical term in one plain sentence.

Intermediate

Short explanations of less common terms.

Expert

Terse. Shows trade-offs and alternatives.

Not sure what something means? Say “explain ERD” (or any term) at any time.

The first implementation prompt

The skill stops at handoff. Paste this into any coding agent.

Read AGENTS.md and every document it links. Summarize the approved MVP, architecture,
data and permission rules, coding conventions, and acceptance criteria. List blocking
contradictions or [TBD] items. Then propose a plan for Milestone 1, Task 1 from
docs/technical/IMPLEMENTATION_PLAN.md, with files to create and how each acceptance
criterion will be verified. Do not write code until I approve the plan.

Frequently asked questions

Does it write any code?

No. It writes planning documents only. Small illustrative snippets inside docs (a config key name, a command already verified in your repo) are allowed, but no application code, packages, migrations or deployments.

Which AI model do I need?

Any capable model. The skill is model-agnostic plain Markdown that follows the open Agent Skills standard, and it also ships as a single pasteable prompt for chat-only tools and local models.

Can I use it on an existing project?

Yes.

Will it invent facts or claim compliance?

No.

Do I have to answer every question?

No.

What if my session ends halfway?

Progress is saved to docs/.start-from-here/STATE.md after every step, and a short project digest (DIGEST.md) keeps names, IDs and decisions. Open any tool with any model and say “resume”. In chat-only tools, save the state and digest blocks yourself and attach them.

Is my data sent anywhere?

The skill makes no network calls of its own.

Which install method should I pick?

Terminal agent with Node 22.20+: npx skills add. Older Node: npx start-from-here install. Claude Code, Codex or Gemini CLI with auto-updates: the plugin or extension. Chat apps: upload the zip, or paste the prompt file.

How do I update it?

Re-run your install command.

Is it free?

Yes. It is open source under the MIT license. You only pay for the AI tool you already use.

My AI has a small context window. Will it work?

Yes — use session mode. Say “session mode” and the work is split into short work packages, one per fresh session, connected by a project digest (DIGEST.md) and a handover file (HANDOVER.md) in docs/.start-from-here/ that keep names, decisions and IDs consistent. The skill recommends it by default for Enterprise runs, more than ~20 documents, small or local models and chat-only tools, and checkpoints at every review gate so later documents stay as good as the first.

What is start-from-here?

An open, MIT-licensed Agent Skill that interviews you with recommended defaults, recommends a stack, gets your brief approval, and then generates a complete set of pre-development documents before any code is written.

What documents does it generate?

PRD, app flow, design system, TRD, architecture with ADRs, database and ERD, API, security threat model, testing, operations, implementation plan, code style, git workflow, AGENTS.md, legal drafts (terms of service, privacy, cookies, compliance, and conditional MSA, DPA and BAA) and open-source files.
