> **Status:** Draft · **Owner:** Lead developer [TBD: name — Founder/PM] · **Last updated:** 2026-10-24 · **Tier:** Standard · **Related:** [ARCHITECTURE](ARCHITECTURE.md) · [SECURITY_ARCHITECTURE](SECURITY_ARCHITECTURE.md) · [API](API.md) · [PRIVACY_POLICY](../legal/PRIVACY_POLICY.md)

All schemas are PROPOSALS until the team approves them. Seed data is synthetic only. No credentials appear here.

## 1. Storage model

| Item | Value |
| --- | --- |
| Primary store | PostgreSQL, managed (AWS). Latest stable version at setup — verify. |
| Other stores | Object storage for attachments and exports (bytes only; metadata in PostgreSQL). No cache, no search index in the MVP (full-text search inside PostgreSQL, A-10). |
| Why | Relational data, transactions, row-level security, full-text search → [ADR-0003](../decisions/0003-postgresql-shared-schema-rls-tenancy.md) |
| Ownership / tenancy model | Multi-tenant pooled: one schema, `organization_id` on tenant tables, RLS → §7 |
| Hosting & region | AWS, one region [TBD: Q-04]; residency requirement: EU customers asked, not yet committed |
| Access layer | [TBD: ORM or query builder — Q-10]. Must support setting `app.org_id` and `app.user_id` per transaction. |
| ID strategy | UUIDv7 generated by the application: time-ordered (good index locality), unguessable enough for URLs, no central sequence. |
| Time & money conventions | Timestamps `timestamptz` in UTC. Money is not stored by TaskFlow (Stripe holds prices and invoices); only Stripe ids and quantities. |
| Consistency | Strong (transactions) for all writes. Eventual only for search vectors (generated columns, so immediate) and Stripe state (reconciled, NFR-14). |

## 2. Data classification

| Class | Definition | Examples in this product | Handling |
| --- | --- | --- | --- |
| Public | Safe to publish | None in the MVP | n/a |
| Internal | Not secret, not public | Task titles and descriptions, project and workspace names, comments, labels, statuses | Auth + tenant checks; never logged in content form |
| Personal (PII) | Identifies a person | User name, email, IP address, user agent, time zone, uploaded files (may contain PII), comment text (may mention people) | Minimize; TLS and encryption at rest; redact in logs; anonymize on account deletion |
| Sensitive / special category | High harm if leaked | None intended. Users are told not to upload special-category data? [TBD: Q-30 Terms wording — counsel]. No health, children's, or card data. | n/a |
| Secrets | Credentials | Password hashes, session token hashes, MFA secrets, one-time token hashes, invitation token hashes | Hash one-way (or encrypt for TOTP seeds); never logged; never returned by the API |

### 3.1 Supporting entity decisions

| Area | Entities | Decision | Reason / link |
| --- | --- | --- | --- |
| Identity | users, credentials, identities, sessions, MFA, verification tokens | Included: all six | F-01; ADR-0005 |
| Authorization | roles, permissions, memberships | Included: memberships only. Roles are an enum on `memberships.role`; no permission table. | Fixed roles (owner/admin/member); matrix in SECURITY_ARCHITECTURE §5 |
| Tenancy | organizations, invitations, workspaces, workspace_members | Included | F-02, F-03 |
| Audit & activity | audit_events, activity_events | Included. Version history of task fields: Excluded (activity events record changes; no revert in MVP) | F-10, F-15 |
| Notifications | notifications, notification_prefs, email_deliveries | Included | F-08 |
| Files | attachments, exports | Included | F-07, F-13 |
| Settings & consent | notification_prefs; user theme and time zone as columns on users; consents | Included prefs. Consent records: Excluded — no marketing email or non-essential cookies (A-09, Q-20) | PRIVACY_POLICY |
| Integration | API keys, webhook endpoints, outbox, idempotency | Included: idempotency_keys, stripe_events. Excluded: API keys and outbound webhooks (no public API, D-08); outbox replaced by `jobs` (ADR-0008) | D-08 |
| Operations | jobs, rate_limits, feature flags, usage counters | Included: jobs, rate_limits, usage_events. Excluded: feature flags (use environment config in MVP) | ADR-0008 |
| Billing | subscriptions, stripe_events | Included. Excluded: plans, prices, invoices, payments, payment methods (live in Stripe) | ADR-0006 |
| Content | labels, comments, templates, soft delete | Included. Soft delete (`deleted_at`) on projects and tasks only (30-day undo window for support) [PROPOSAL] | F-04, F-05 |
